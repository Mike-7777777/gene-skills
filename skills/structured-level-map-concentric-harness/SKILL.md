# 结构化关卡与环绕聚落地图生成（五层同心拓扑 + Generator-Evaluator 闭环）

将包含“野外出生 $\rightarrow$ 进镇补给问路 $\rightarrow$ 出镇探索危险区/矿洞”的关卡地图生成，从单次无约束随机撒点重构为 **「五层同心拓扑生成架构（Generator）」+「五维独立算法检验器（Evaluator）」** 的迭代闭环，彻底根除出生即遇怪、怪追进镇、大路刷怪堵死、城镇成不可达孤岛以及大片无功能死地等关卡设计缺陷。

## 适用场景 (When to Use)

- 设计或生成包含安全聚落（城镇/营地）、自然屏障（群山/水体/悬崖）、主干道网络、生态缓冲带、多阵营野外怪物区及目的地副本入口（如旧矿洞）的 2D 俯视角地图；
- 解决随机生成地图中“出生点与安全镇之间刷怪拦路”、“怪物追进安全区不脱战”、“主干道上刷怪”、“不同怪物杂乱混居”或“NPC 被障碍物卡死”的问题；
- 构建浏览器可直接游玩的 2D 俯视角探索地图原型或关卡数据文件。

## 基线四大劣化症状防御靶向 (Baseline Symptoms to Eliminate)

1. **地形死锁与出生拦路**：外围山脉闭合把城镇封死；或在「玩家初始进入点 $\rightarrow$ 第一座安全城镇」的必经引导路上刷出敌对怪物。
2. **怪镇混杂与追击进镇**：安全区缺乏物理围栏与外围缓冲环，危险刷怪区紧贴镇口；或怪物追击玩家跨入城镇安全区后不脱战、不归位。
3. **主干道失守与族群碎片化**：本应承担低状态安全通行职责的主干道周围刷出敌对怪物；不同习性的怪物随机混杂，缺乏扇区领地内聚感。
4. **无功能死地与 NPC 动线断裂**：地图存在大面积无交互、无生态、无路线引导的空白死地；或镇内建筑缺门、门前被石头树木堵死导致 NPC 寻路断裂。

## Generator 侧：五层同心拓扑生成法 (Five-Layer Concentric Generation)

严格按照从宏观骨架到微观动线的 5 个阶段顺序写入网格数据，严禁先随机撒障碍物再凑路线：

### 阶段 1：宏观外围屏障与强制通行豁口 (Macro Barrier & Forced Passes)
- 在地图外圈构建厚度 $\ge 2$ 格的不可通行自然屏障（如群山岩体、深水悬崖），防止斜角穿模与边界漏出。
- 在指定方位强制切割宽度 $\ge 3$ 格的通行豁口（如南/西迎宾山口、北/东深山矿洞通道），直通盆地内部，从拓扑根源杜绝死锁孤岛。

### 阶段 2：保护性主干道骨架锁定 (Protected Road Skeleton First)
- 先铺设绝对不刷怪的主干道路网，依次连接：`地图边缘出生点 -> 城镇正门 -> 城镇中心广场（向导/补给点） -> 出镇大门 -> 远端目标入口（如旧矿洞）`。
- 将主干道本体、两侧 1 格路肩及城门外 $3 \times 3$ 集散区写入 **受保护走廊掩码（`ProtectedCorridorMask`）**：
  - 严禁后续任何阶段在掩码内放置阻挡物（山石、树木、墙体）；
  - 严禁在「出生点 $\rightarrow$ 城镇正门」的引导走廊及主干道路肩生成任何敌对怪物；
  - 沿主干道每隔 $4 \sim 6$ 格布置路标或路灯，提供清晰的视觉动线引导。

### 阶段 3：安全聚落核心与 $\ge 3$ 格生态缓冲环 (SafeZone Core & Buffer Ring)
- **核心城镇安全区（`SafeZone`）**：
  - 外围用围栏/城墙合围并在主干道交汇处留门；
  - 内部严禁生成任何敌对怪物或危险地皮；
  - **安全区强制脱战契约（Leash & Disengage）**：任何野外怪物一旦追击玩家触碰 `SafeZone` 或外围缓冲带边界，或者超出自身领地拴绳半径（Leash Radius），必须立即清空仇恨并沿原路返回出生领地，绝不允许跟进镇内。
- **生态缓冲环（宽度 $\ge 3$ 格）**：
  - 在城镇围栏外侧强制铺设一圈宽度 $\ge 3$ 格的中立生态缓冲带（如安全草甸、果林、溪流采集点、温顺动物区）；
  - 确保任何敌对怪物领地或危险刷怪地皮到 `SafeZone` 边界的最小切比雪夫/曼哈顿距离 $D_{\text{safe\_danger}} \ge 3$ 格。

### 阶段 4：外围危险区扇区化与同族高内聚聚类 (Sectorized Faction Clustering)
- 将缓冲环外侧、群山内侧的野外区域（主要分布在“出镇前往旧矿洞”的探索半区及侧翼林地/岩坡）按方位划分为独立生态扇区，消除无功能空白死地（每个扇区必须绑定明确的功能：主线探索区、侧翼林地采集/狼群猎场、岩坡矿脉/精英驻地）：
  - **单连通分量约束**：同一怪物族群的专属领地地皮 8-邻域连通分量数必须 `== 1`（整片连贯聚合，配有明显的领地环境特征如兽骨窝、营地旗帜或战利品点，严禁全图零散乱撒）；
  - **异族隔离约束**：不同敌对怪物族群扇区之间的最小曼哈顿距离 $D_{\text{inter\_faction}} \ge 12$ 格（或由主干道/山脊物理隔断）。

### 阶段 5：NPC 建筑功能锚点与全链路动线织网 (NPC Routine Wiring)
- 每座镇内功能建筑（向导站、商人铺、居民屋、铁匠台）必须成套包含：`起居点 + 功能交互点 + 朝向主干道的门（Door）`。
- 从每扇门外第 1 格自动铺设支路汇入受保护主干道，并为向导、商人与巡逻居民配置闭环活动轨迹（在各自锚点与中心广场间走动，不卡墙、不走出安全区）。

## Evaluator 侧：五维独立算法验收闭环 (Five-Dimension Evaluator Loop)

生成地图数据后，必须运行只读评估器（Evaluator）验算以下 5 项硬性算法指标，任一单项不达标必须根据违规坐标 `(x, y)` 自动修正后再交付：

1. **D1 宏观拓扑连通性（权重 25%）**：运行 4-邻域 BFS 验证 `出生点 -> 城镇大门 -> 中心向导 -> 出镇大门 -> 矿洞入口` 100% 连通；外围山体屏障厚度 $\ge 2$ 格；城门外 $3 \times 3$ 零阻挡。
2. **D2 安全/危险隔离与引导路净空（权重 25%）**：验证 `SafeZone` 及「出生点 $\rightarrow$ 城镇」引导走廊内敌对怪物数 `== 0`；所有危险区/怪物领地距 `SafeZone` 边界最小距离 $D_{\text{safe\_danger}} \ge 3$ 格；验证怪物 AI 具备触碰安全区边界立即脱战归位（Leash Reset）逻辑。
3. **D3 同族怪物内聚度与死地消除（权重 20%）**：验证每种怪物专属领地的 8-邻域连通分量数 `== 1`，异族最小间距 $\ge 12$ 格，且野外各象限均具备明确功能锚点（无大片空白死地）。
4. **D4 NPC 全链路 A* 动线与支路接驳（权重 15%）**：对所有 NPC 运行 A* 寻路验证 `室内锚点 -> 房门 -> 广场中心` 100% 导通，房门外第 1 格道路接驳率 `== 100%`。
5. **D5 占地碰撞零重叠与地形规则合规（权重 15%）**：验证所有建筑、山石、树木与多格设施的完整 Footprint 碰撞重叠数 `== 0`，且零侵占 `ProtectedCorridorMask`。

## 严禁事项 (Safety Boundaries)

- 严禁在玩家出生点到第一座安全城镇的开场引导路径上布置主动索敌怪物。
- 严禁允许野外怪物追击玩家进入城镇安全区而不脱战归位。
- 严禁让 Generator 自我打分跳过 BFS / 距离 / 连通分量算法校验。
